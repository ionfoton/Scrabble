# Scrabble
Scrabble Romania

## Features

| Feature | Description |
| --- | --- |
| 15x15 board with bonus squares | Standard Scrabble board layout with double/triple letter and word score cells plus center star. |
| Drag-and-drop tile placement | Move tiles from the rack onto the board using drag-and-drop. |
| Rack management | Shuffle rack tiles and recall placed tiles back to the rack. |
| Turn-based play | Tracks turns and enforces first-move center placement and board connectivity. |
| Scoring engine | Computes scores with letter and word multipliers and updates total score. |
| Game state controls | Submit moves, pass turns, and start a new game. |
| Endgame detection | Detects game completion when both the bag and rack are empty. |
